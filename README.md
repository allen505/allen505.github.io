# Allen Abraham - Professional Portfolio

This is the repository for the professional portfolio website of Allen Abraham, a Software Engineer, Data Engineer, and System Designer.

The website is hosted using GitHub Pages and can be viewed live at: **[allen505.github.io](https://allen505.github.io/)**

## Overview

This repository contains the source code for my personal portfolio website, showcasing my:
- Work experience and professional timeline
- Educational background
- Key projects and open-source contributions
- Technical skills
- Volunteer work and achievements

## Tech Stack

The portfolio is built using standard, reliable web technologies for high performance and compatibility:
- **HTML5**: For semantic page structure.
- **CSS3 / SCSS**: For styling and responsive design.
- **JavaScript (Vanilla)**: For interactivity, animations, and DOM manipulation.
- **Bootstrap 5**: For responsive grid layout and UI components.
- **Plugins**: Powered purely by modern Vanilla JavaScript and native Bootstrap 5 components.
